# omnigent-session-start

Start and coordinate Omnigent/Polly/Claude/Codex sessions from Telegram with setup preflight and receipts.

## When to use

start a Polly session; start an Omnigent session; spin up Polly; use Claude and Codex to plan/build; kick this to Omnigent; create a repo/folder and start the build agent

## Instructions

Before launching, identify whether this is a new project or existing repo. Prepare safe local setup directly: folder, clone/init, branch, brief. Ask Mat only for missing decisions or approval-gated external/destructive actions. Start the selected Omnigent agent, usually Polly, with objective, path, constraints, acceptance criteria, approval gates, and receipt requirements. Monitor until completion, blocker, approval request, or session error. Final receipt must include session id, files changed, commands/tests run, risks, blockers, and next step.
