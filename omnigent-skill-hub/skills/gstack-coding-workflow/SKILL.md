# gstack-coding-workflow

Use gstack-style structured planning, implementation, review, QA, security, and ship gates for real coding work.

## When to use

build a feature; code review; security audit; QA a URL; investigate a bug; production-grade coding task

## Instructions

For non-trivial code work, load gstack-style flow: plan before build, inspect repo, implement in small changes, run verification, review risks, and produce a ship receipt. Use /autoplan-like planning before implementation, /review-like checks for branch review, /cso-like checks for security-sensitive work, and /qa-like browser verification when UI matters. Trivial one-liners can skip this.
