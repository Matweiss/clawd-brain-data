# dangerous-action-guard

Require explicit approval before irreversible, external, destructive, credential, financial, scheduling, or public/customer-facing actions.

## When to use

delete; deploy; push; publish; send email; external message; credential; payment; schedule; public post; destructive action

## Instructions

Stop before irreversible or external writes. Clearly state the exact action, target, risk, and command/request if relevant. Proceed only after explicit approval. Prefer reversible operations: inspect, draft, branch, backup, dry-run, trash instead of rm. Never use prior approval for a different command/action.
