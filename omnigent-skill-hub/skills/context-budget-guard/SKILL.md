# context-budget-guard

Watch context usage during long sessions and checkpoint/summarize before context overflow.

## When to use

long session; multi-hour task; complex build; many files; extended investigation; context getting large

## Instructions

At the start of long work, establish checkpoints. Periodically summarize current goal, decisions, files changed, commands run, blockers, and next step. If context grows, write a durable note or receipt before continuing. Prefer concise state transfer over re-reading entire history.
